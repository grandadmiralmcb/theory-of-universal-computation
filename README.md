## Core Idea (one paragraph)

Reality consists of information expressed through syntactically bound, composable functions. Expression trees formed from a small set of primitives are evaluated under binding contexts. Local sequential evaluators construct high-coherence trajectories; cost minimization selects among possible rewrites; amplitude-weighted multi-path reduction supplies interference. Classical physics appears as the continuum limit of lowest-cost sequential evaluation under persistent bias. Quantum-like behavior appears when multi-path amplitudes remain coherent. Spacetime order itself is not fundamental but arises from sequential evaluation and a bounded signal speed.
